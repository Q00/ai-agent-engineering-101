## 1. 가게 선택과 기억

`market_buyer.py`는 가게 목록, 공개 후기와 자기 거래 기억을 모델에 전달하여 가게
이름과 선택 이유를 받는다. 선택한 가게와 `buyer.py`가 A2A로 협상한다. 모델은
기존 로그인으로 호출하는 Codex CLI `gpt-6-astra`, reasoning `low`이다.
제안 금액은 HTTP 송신 직전에 코드가 예산과 비교하며, 영수증의 품목과 가격도 검사한다.

기억은 SQLite `.market/buyer-memory.sqlite3`의 `trades`에 누적한다. 실행 ID, UTC 시각,
가게 이름, 품목, 예산, 결과, 가격, 원본 영수증, 후기와 선택 이유를 저장한다.
URL은 재시작마다 바뀌므로 이름으로 기억한다. 모델에는 가게별 최근 30건의 결과 통계,
최근 5건 상세, 같은 품목 최근 3건을 제공한다. 협상은 600자 이하 요약과 최근 두 번의
교환을 사용하고, 예산과 task ID는 요약이 아닌 명시적 상태로 보호한다.

## 2. 후기의 표현과 평가

공개 후기와 개인 기억은 구분한다. 공개 후기는 가게별 최신 최대 10개의 평균과 개수,
최근 3개 본문 각 400자를 전달한다. 후기와 가게 이름은 명령이 아니라 신뢰하지 않는
데이터라고 프롬프트에 명시했다. 이것이 모든 프롬프트 공격을 막는다는 주장은 하지 않는다.

후기는 정상 영수증 4점, 검증된 영수증 불일치 1점, 결렬이나 통신 실패 2점이다.
예산 부족과 연결 오류를 사기라고 단정하지 않는다. 성사와 결렬 모두 결과 JSON에
후기를 출력하지만, Round 2 공개 보드는 서명·주문 조건을 통과한 거래만 표시한다.
따라서 로컬 후기 수와 공개 후기 수는 다를 수 있다.

## 4. 서명 구현의 실패와 수정

초기 판매자는 서명이 없어 서명 검사 3개가 실패했고 실제 후기에서도 누락이 지적됐다.
기존 `shop_key.pem`으로 `{shop,item,price,task}`를 키 정렬·공백 없는 UTF-8 JSON으로
직렬화하여 Ed25519 서명하고 base64 `sig_seller`를 추가했다. `task`는 실제 A2A ID이며,
가격은 정수로 서명한다. 수신 시 120이 120.0이 되는 문제는 키트의 정수 정규화와 맞췄다.

첫 오프라인 검사에서 SDK에 없는 `TaskUpdater.fail`을 발견해 `failed`로 수정했다.
[실패 원문](logs/lab2-20261020T122406355654Z/offline-tests.log)을 보존했다.
서명에 성공한 뒤에만 완료 영수증을 내보내며, 키는 커밋하지 않는다. 이는 10월 20일의
기존 구현 이력이며 이번 제출 정리에서 새로 수정한 코드가 아니다.

## 5. 필수 도전

### 도전 1: 거래와 후기에 따른 가격 변경

변경 전에는 높은 첫 가격, 긴 협상, 서명 누락에 관한 후기가 있었다. 최초 제안
125/225/325를 낮추고, 첫 가격을 최저가의 110%인 110/198/286 이하로 제한했다.
최저가 100/180/260은 유지했다. 작은 마진, 빠른 합의, 추가 요금 없는 영수증과
명확한 최저가 안내를 적용했다. 선택형 가위바위보는 구매자 승리 시 최저가 할인,
패배·무승부 시 현재 가격 유지이며, 참여와 별도의 구매 합의가 필요하다.

평균 가격은 내려갔지만 관찰된 점유율 증가는 없다. 라운드 규칙, 서명, 후기, 기간,
품목 구성도 함께 달라졌으므로 가격 변경이나 할인 게임이 평점·성공률을 높였다는
인과관계는 주장하지 않는다. 통제된 A/B가 아니라 실제 운영 전후의 관찰 비교다.

## 6. 배포, 검증과 원본 보존

`daintlabK` 서버에서 기존 `eraseanything` 기반 Python 3.10.22 전용 `.venv`,
인증된 Codex CLI와 cloudflared를 사용한다. tmux의 시장 키트가 판매자와 구매자를
함께 실행한다. 기존 이름·키를 유지하고 `MARKET_OWNER`로 GitHub 소유권을 연결한다.
재시작은 사용자가 수행했으며, 이번 작업에서는 conda·개인키·거래 기억을 변경하지 않았다.

```bash
submissions/26520024/week-07/.venv/bin/python scripts/market_kit.py join \
  --dir submissions/26520024/week-07 \
  --market https://market.ourolabs.ai/ --name leeuichann --tunnel
```

않는다. 현재 온라인 확인은 마감 시 상태를 보장하지 않으므로 마감까지 계속 운영해야 한다.
