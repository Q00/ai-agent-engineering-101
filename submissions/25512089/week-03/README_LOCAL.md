This pack is intentionally incomplete in one important way: it contains no fake experiment
results. `results.csv` has only the required header, and `REPORT_TEMPLATE.md` must be turned
into `REPORT.md` only after the real API runs.

Recommended order:

1. Copy these files into `submissions/25512089/week-03/`.
2. Commit `tasks.json` before any experiment run.
3. Set OpenRouter environment variables.
4. Run `python run.py --all --runs 3`.
5. Inspect `results.csv` and all 9+ log files.
6. Write `REPORT.md` from the real evidence.
7. Run the official checker.
