# 옮기기 실행 문서 (설계 20-5, 2026-11-06)

`week-08-move` 브랜치의 새 층을 실제 하네스로 옮기는 순서. 단계마다 확인하고 다음으로 간다. 밤(00-08시)에는 하지 않는다 (R9).
명령은 `submissions/26512070/week-08`에서 PowerShell로.

## 0. 준비
- 브랜치 테스트: worktree에서 `py -m unittest discover -s tests` (163개; `test_index`는 가끔 실패하는 기존 문제).
- 실제 폴더에 커밋 안 된 코드 변경이 없는지: `git status --short` (logs/ 와 memory/ 만 있어야 함).
- 그림자 실행 결과 확인: 메타 하네스 한 주기 (`py -m harness.meta`, HARNESS_OUT을 임시 폴더로).

## 1. 합치기 = 접점 T1-T7 적용 (buyer, restock, 리뷰는 다음 실행부터)
```
git merge --no-ff week-08-move
```
- 확인 (5분 안):
  - 새 buyer 주문의 도구 기록에 키가 있음: `Select-String -Path memory\raw\tools\buyer-$(Get-Date -f yyyyMMdd).jsonl -Pattern '"keys":{"order"' | Select-Object -Last 1`
  - 오류 없이 주문이 끝남: `logs\market-kit.log` 꼬리에 `[order ...]`와 결과가 이어짐.
- 되돌리기: `git revert -m 1 <합친 커밋>` (이력은 지우지 않는다).

## 2. seller 재시작 (T1 seller 쪽)
```
Get-CimInstance Win32_Process -Filter "name like 'py%'" | ? { $_.CommandLine -like '*seller.py*' } | % { Stop-Process -Id $_.ProcessId }
```
- 키트 watchdog이 60초 안에 다시 띄움. 확인: `memory\raw\tools\seller-*.jsonl` 새 줄에 `"keys":{"task"`.
- 되돌리기: 1의 되돌리기 후 같은 명령.

## 3. outer → 새 실행기
```
Get-CimInstance Win32_Process -Filter "name like 'py%'" | ? { $_.CommandLine -like '*outer.py*' } | % { Stop-Process -Id $_.ProcessId }
Start-Process powershell -WindowStyle Hidden -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','ops\harness.ps1'
```
- **outer.py와 동시에 돌리지 않는다** (둘 다 수집하고 forum에 글을 쓴다).
- 확인 (10분 안): `memory\bus\status\outer.json`의 note가 `harness.run`; `memory\harness\score_class.json`, `participants.json` 생김;
  `logs\harness-console.log`에 오류 없음; `py -m harness.ops` 결과.
- 작업 스케줄러 2번(outer.ps1)을 harness.ps1로 바꿈 (PC 재시작 대비).
- 되돌리기: 새 실행기 프로세스(`-m harness.run`)를 멈추고 `ops\outer.ps1`을 같은 방식으로.

## 4. 현황 페이지 재시작
```
Get-CimInstance Win32_Process -Filter "name like 'py%'" | ? { $_.CommandLine -like '*ops.status_page*' } | % { Stop-Process -Id $_.ProcessId }
Start-Process py -WindowStyle Hidden -ArgumentList '-m','ops.status_page','--loop' -RedirectStandardOutput logs\status-page.log
```
- 확인: 페이지 요약 탭이 Class view(학생 순위)로 바뀜.
