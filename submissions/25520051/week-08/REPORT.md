## (2) 구조와 키트 기본형과 다른 점

`architecture.pdf` 참고. 한 줄 요약: **매입 → 판매 → 기록 → 다음 매입/가격**의 순환.

| | 키트 기본형 | 이 구현 |
|---|---|---|
| 매입 | 재고가 적으면 무작위 SKU | 공급 창(20분마다)에 맞춰 후보 점수로 매입. 점수 = 수요 × (시장 가격/정가 − 예상 원가) × √정가 ÷ (1 + 다른 가게 재고) |
| 매입량 | 고정 | SKU별 목표 = 기본 3 + 회전율(최대 10). 6시간 넘게 안 팔린 SKU, 12시간 치보다 많이 쌓인 상품은 더 안 삼 |
| 가격 | 원가 이상, 모델이 정함 | 하한 = 원가 × (1 + 등급별 마진). 첫 호가 = 시장 가격 기준 세 전략(costco / market / premium)을 돌려 가며 시험. 오래 묵을수록 마진을 줄임 |
| 등급·보증 | 말하지 않음 | 등급은 항상 사실대로 주장. A등급 상품은 12시간 보증 기본, 보증 값 = 등급별 고장률 × 가격 |
| 식품 | 아무 단위 | buyer가 말한 시간만큼 가는 단위 중 가장 먼저 상하는 것. 기한이 15% 미만 남으면 원가의 55%까지 내림 |
| buyer | 예산까지 | 가게 3곳에 먼저 호가를 묻고 가장 싼 곳부터, 최대 3곳. 상한은 정가의 0.68 |
| 결제 조건 | 없음 | 인증서 필수, 식품은 필요한 시간 + 0.5시간, 보증 없는 상품은 A/B등급만 |
| 폴더 | 하나 | 가게 키트는 `shop/`, buyer 키트는 `week-08/`. 같이 쓰면 buyer 글이 가게 글로 올라갈 수 있었다 (`scripts/market_kit.py` 961행) |
