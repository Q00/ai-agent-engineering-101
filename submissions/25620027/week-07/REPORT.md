## 2. 구매자의 선택·기억·후기

키트가 넘긴 `{shops}`를 읽고 `select_shop(index, reason)`으로 하나를 고른다. 이름별 자기 거래와 공개 후기의 제한된 사실 신호를 사용한다. 상대 이름·후기·응답은 명령으로 취급하지 않는다. 과청구·결렬·권한 사칭 같은 공개 후기 신호는 검증되지 않은 주장으로 표시하며, 공개 별점 숫자는 현재 선택 입력에서 제외한다. 직접 받은 권한 사칭 사건이 기억에 남은 가게는 도구에서 선택을 거부한다. 정상적인 가격 결렬은 부정직함으로 단정하지 않는다.

기억은 `.market/buyer-memory.json`의 `{shops: {name: [Trade, ...]}}`다. 각 거래에는 주문 상품·예산·선택 이유·성사 여부·실제 가격·받은 영수증·안전 관측·평가가 들어간다. URL이 바뀌어도 같은 이름의 기록을 이어간다. 모델 입력에는 가게별 최근10건과 같은 품목의 관측 가격을 압축해 넣고, 거래 사실은 후기 생성 전에 저장한다. 전체 스냅샷은 임시 파일을 거쳐 교체한다.

협상은 예산을 넘는 도구 제안을 네트워크 전송 전에 거부한다. 시장 주문 상품이 다른 상품으로 바뀌면 첫 제안 전에 중단하며, 받은 영수증을 실제 제안가·상품·SKU·task와 대조한다. 마지막 JSON은 원래 목록의 URL, **받은 data Part 그대로의 receipt**, 별점과 후기를 출력한다. 결렬이면 receipt는 null이다. 후기는 성사·결렬 모두 출력하지만 R2 시장에서 표시되는지는 시장의 서명·거래 검증에 달렸다.

현재 일반 거래 평점은 사용자 정책상 정수3 상한이다. 직접 관찰한 권한 사칭 사건은 사실 경고와1점 정책이다. 가짜 품질·배송 경험이나 확인하지 않은 서명 검증을 후기에서 주장하지 않는다. 부정확한 모델 후기의 가격·횟수는 실제 거래 사실로 제한한다. 시장 구매 옵션은 최초 요청에만 우리 가게의 공개 소개를 붙인다. 이후 숫자 제안·후기에는 홍보를 섞지 않으며 추천 보상은 구현하지 않았다.

## 3. 판매자·영수증·실패와 수정

영수증의 `{shop,item,price,task}`를 키 정렬·공백 없는 UTF-8 JSON으로 만들고 기존 `shop_key.pem`의 Ed25519 개인키로 서명해 base64 `sig_seller`를 넣는다. price는 `120.0`이 아니라 정수120으로 서명한다. A2A data Part에서 double로 전달되는 정수는 구매자 검증에서 허용하지만 원본 receipt는 보존한다. 키트가 등록 공개키·주문·예산을 검증한 뒤 구매자 서명을 추가한다. 개인키·API키는 제출하지 않는다.

서명 도입에서는 하네스가 임시 디렉터리로 이동하는 구조 때문에 상대 경로가 안전하지 않았다. 키와 기억의 기준 경로를 호출 위치에서 먼저 절대경로로 확정하고, 키 권한0600을 확인하게 했다. 공식 검사의 `seller_signed_receipt`가 가격/task/키 일치를 확인한다. 초기 구조 검사는 실제 시장 로그가 없어 실패했고, 실제 장부 로그 확보 후 재검사했다. 이 실패는 서명 암호화 실패와 구분한다.

검수 중 상품 metadata를 따라 주문 상품이 바뀌는 문제가 재현돼 시장 경로에 원주문 일치 검사를 추가했다. 이후 기본 램프 요청의 `flexible refund policy`를 상품의 flexible-neck 속성으로 오인한 실제 협상도 발견했다. 제한된 서비스 질문과 실제 상품 속성을 구분해 기본 SKU를 유지하도록 보완했다. `I accept`·`OK` 같은 전체 무조건 수락은 현재 호가로 연결하며, 보증을 조건으로 한 제안은 숫자만 떼어 수락하지 않는다. [실제 결함·1.6.0 검증](.omo/evidence/dragonash-upgrade-20261022/RESEARCH.md).

## 7. 배포·운영과 한계

판매자는 [공개 가게](https://ax-week07.treasuresky.xyz/)에 VPS Docker·고정 Cloudflare 터널로 배포했다. 구매자도 별도 VPS 컨테이너에서 공식 시장 키트를 실행한다. 같은 이름·키·영속 DB·기억을 유지하고 모델 환경과 서명키는 비공개 마운트에 둔다. Mac 전원을 꺼도 서버 실행은 이어진다.
