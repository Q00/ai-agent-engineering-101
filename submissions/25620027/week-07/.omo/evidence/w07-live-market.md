### 공개 터널 문제와 조치

- 첫 자동 터널은 Agent Card에 HTTP 404를 반환했고, 키트가 `the tunnel URL did not answer within 120 s`로 종료했다. 시장 등록 전 실패다.
- HTTP/2로 재시도한 터널에서도 연결은 성립했지만 404가 계속됐다. 기존 기본 Cloudflare 설정에 hostname 기반 ingress와 `http_status:404`가 있는 것을 값 출력 없이 확인했다. 해당 시도는 Ctrl+C로 종료했다. 원문: `logs/cloudflared-attempt-2.log`.
- 기존 설정을 수정하지 않고 과제 전용 설정을 명시한 새 quick tunnel을 시도했으나 서비스가 429를 반환했다. 원문: `logs/cloudflared-attempt-3.log`.
- 따라서 공식 README에 있는 localhost.run의 익명 SSH 터널을 대안으로 시도한다. 연결 성공·등록 완료로 미리 판정하지 않는다.
