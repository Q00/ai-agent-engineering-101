# 6주차 현행 하네스 과제 실행 계획

- 공식 기준: upstream 3defe07be2f0f5d78e11a839aa5210f633e82700.
- 5주차 market/host.py의 모델→function tool→관찰→재판단 루프를 이식한다.
- 모델: 기존 실험과 같은 OpenAI gpt-4.1-nano-2025-04-14. 새 결정은 모델이 내리고, 가격·예산·상태·중복 보호는 도구 경계에서 코드로 검사한다.
- market_a2a에 새 현행 구현을 두고 구판 실험 코드·CSV·로그는 보존한다.

- Buyer: 카드 발견, 같은 taskId와 버전 헤더, 모델 제안·종료 도구.
- Catalog: 3,000개 이상 의미 있는 생성 상품과 속성 검색. 전체 카탈로그를 모델 입력에 붙이지 않는다.
- Challenge 1: 상품명을 주지 않는 설명 요청, 영수증 상품 일치와 해당 상품 reserve 보호. 원문 JSON-RPC와 모델·도구 로그를 남긴다.
- Challenge 2: 20개 실제 A2A 가게 카드, 다른 상품군과 가격, 하나의 총예산, 여러 가게 동시 협상. 모델이 가게·예산 분배를 선택하고 예약 한도·중복은 코드로 보호한다.
- 현재 공식 trade test 21개 전부, 필수 챌린지 1·2, 정적·타입·의미 있는 경계 검사를 실행한다.
- 실패 원문을 보존하고 작은 단위 커밋으로 수정 이력을 남긴다. 실제 통과 로그와 5항목 REPORT를 작성한다.
