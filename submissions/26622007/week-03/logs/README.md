# 실행 기록 읽기

최신 제출 CSV의 각 `run`은 다음 두 원본 파일에 대응한다.

- `<run>.console.log`: 실제 실행 명령과 표준 출력의 최종 요약.
- `<run>.jsonl`: 전체 공고 입력(`http_request.payload.messages`), 입찰·확신도·이유(`proposal`), 낙찰(`award`), 심사·수행·위임·오류 이벤트.

콘솔만으로는 전체 협의 내용을 볼 수 없다. [실행별 표](../submission/RESULTS_BY_RUN.md)에서 두 파일을 함께 연결한다. 45회 최초 시도와 16회 429 복구, 각각 61개 콘솔과 61개 JSONL을 원래 위치에서 바이트 그대로 복사했으며 기록을 편집하거나 합성하지 않았다. 이전 실험·검증 기록도 그대로 보존한다.
