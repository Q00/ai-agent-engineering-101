## 재귀 위임과 오류 처리

[최종 확장 테스트 15개](logs/16-unittest-live-replay.log)가 통과했다.

- 최초 요청자를 C로 바꾸어도 동일 Worker 유형들이 협업한다.
- A가 B에게 위임하고, B가 하위 작업을 다시 A에게 맡겨도 교착 없이 완료한다.
- 준비된 후속 작업은 관계없는 느린 작업을 기다리지 않는다.
- 실패한 선행 작업의 후속 작업만 blocked로 만들고 독립 결과를 보존한다.
- 순환·누락 의존성, 잘못된 JSON과 점수, 깊이·작업·호출 예산 초과를 거절한다.
- 같은 Worker의 중복 모델 호출과 논리 자원의 read/write·write/write 충돌을 막는다.
- 취소 시 자식 작업을 정리하고 자원 lease를 해제한다.
- 실제 실행 두 개가 동시에 진행되어야 끝나는 테스트를 통과했다.

중첩 재위임은 [6개 작업 데모](logs/11-demo-rotation-audit.json)와 테스트에서 검증했다. 실제 모델 사례는 하위 위임 한 단계까지 실행됐다.
실제 LLM이 자율적으로 더 깊은 계획을 세웠을 때의 품질까지 검증했다고 주장하지 않는다.
