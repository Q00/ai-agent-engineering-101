# 시장 로그 보관 및 복원

GitHub의 파일당 100 MiB 제한으로 원본 로그 두 개를 무손실 gzip으로 보관한다. 압축 대상은 기존 커밋 `352360c20d241e516dd3eab2a8a87afadd85821b`에 들어 있던 바이트 그대로이며, 줄 삭제·발췌·내용 편집은 하지 않았다. 실행 중 로그의 이후 추가 내용은 이 스냅샷에 포함되지 않는다.

압축본과 원본 크기·SHA-256은 [보관 목록](logs/push-ready-352360c/manifest.json)에 있다. 이 목록의 이력 미변경 설명은 압축본을 준비하던 시점의 기록이다. push 실패 후 사용자 승인으로 해당 미전송 커밋 한 개의 저장 형식을 변경했으며, 이전 커밋은 로컬 백업 브랜치 `backup/week-08-before-log-compression-352360c`에 보존한다. 대용량 원본을 포함하는 백업 브랜치는 GitHub에 push하지 않는다.

week-08 폴더에서 표준 Python만으로 압축본을 검증할 수 있다.

```bash
python restore_market_logs.py --verify-only
```

새 체크아웃에서 과제의 원래 로그 경로로 복원한다.

```bash
python restore_market_logs.py
```

복원 경로는 `logs/market-kit.log`, `logs/market-kit.log.1`이다. 같은 내용이 이미 있으면 건너뛰고, 다른 내용이 있으면 덮어쓰지 않고 중단한다. 현재 운영 중인 원본 로그에 적용할 필요는 없다. 복원된 대용량 원본은 `.gitignore`로 재커밋을 방지한다.

압축본은 원문을 복원할 수 있는 보관 형식이며, 과제에서 요구하는 파일 경로는 복원 후 제공된다. 압축 제출 형식의 인정 여부는 담당자의 판단이며 이를 자동 충족으로 간주하지 않는다. 다른 실행·제출 요구사항은 별도 점검이 필요하다.
