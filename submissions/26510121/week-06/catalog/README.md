# 카탈로그 출처와 범위

`products.jsonl`은 `generate.py`가 만든 원본 합성 데이터다. 외부 상품 데이터·가격을 사용하지 않는다.
5개 용도 × 3개 재질 × 4개 색상 × 5개 높이 × 10개 너비 = **3,000개**의 고유 상품이다.
각 행에 고유 ID, 이름, 설명, 속성, 비공개 최저가가 있다. 치수 단위는 cm, 가격은 과제의 추상 단위다.
책 수용량·가격은 재현 가능한 합성 공식이며 실제 제품의 적재 능력이나 시세를 뜻하지 않는다.

재생성: 이 제출 폴더에서 `python catalog/generate.py`. 동일한 바이트를 생성한다.
기본 3종 판매자와 구분해 `python seller.py --catalog catalog/products.jsonl --port 9999`로 사용한다.

지원 조건은 용도(책 보관·앉기·조명·작업대·문 달린 보관), 재질, 색상, 최소 책 수,
최대 높이·너비다. 미지원 조건이나 수치가 없는 상대적 크기는 모델이 추가 설명을 요청한다.
요청 해석은 모델 판단이므로 원문 의미를 잘못 읽을 위험은 남는다. 실행 검사는 별도 작성한
정답 조건으로 실제 선택을 재검사하며, 모든 자연어 표현을 이해했다고 주장하지 않는다.
