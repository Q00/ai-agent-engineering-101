## 실습과 과제 구현의 구분

완료 증거: 프로토콜 22개 확인 항목은 `logs/lab/20261017T034522.256182Z/`,
API 하네스 연결 4개 확인 항목은 `logs/lab/20261017T040106.607650Z/`에서 통과했다.
이 숫자는 실습 실행 도구의 확인 항목 수이며 공식 trade test의 21개 실행과는 다르다.

`lab/reference/`는 강의 제공 예제를 수정하지 않고 복사한 것이다. 규칙 기반 예제를 실행해 프로토콜을 배우는 단계이며, 하네스가 판단하는 최종 판매자·구매자 구현은 아직 아니다. 실습 결과를 과제의 공식 trade test 결과로 대신 제출하지 않는다.

모든 작업은 이 학생의 제출 디렉터리 안에서 진행하고, 원본 로그는 수정하지 않는다. API 키·토큰·.env와 가상환경·다운로드 실행파일은 커밋하지 않는다.
