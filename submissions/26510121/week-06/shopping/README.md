# 도전 2의 재현 가능한 가게와 장보기 목록

외부 데이터 없이 `generate.py`로 만든 자체 합성 가게 20개다. 가구 용도 5개마다 가게가 4개 있고,
각 가게에 공통 흰 나무 상품 하나와 가게별 파란 금속 대체 상품 하나가 있다. 가격과 대체 상품이 다르다.
서버는 `shops/*.jsonl`의 비공개 최저가를 읽는다. `shops/*.json`의 이름·참고 가격대는 공개 카드에 싣는다.
참고 가격은 확정 호가나 최저가가 아니며 실제 가격 판단은 기존 판매자 모델이 한다.

구매자의 입력은 실제 서버에서 받은 Agent Card 디렉터리와 `shopping-list.json`뿐이다.
`shops.json`과 비공개 카탈로그를 구매자에게 넘기지 않는다. 목록에는 정확한 상품 ID와 충분한 설명,
하나의 총예산 1,500이 있다. 실제 검증기가 서버를 띄워 URL·카드 디렉터리를 새 로그 폴더에 저장한다.

재생성: 이 제출 폴더에서 `python shopping/generate.py`.
실제 검사: `python -u lab/check_shopping.py` (로컬 키 필요, 기본 모델 유지).
기존 공식 테스트와 독립된 `logs/challenge-2/run-<UTC>/`에 매번 새 원본 로그를 기록한다.

모델이 구매처·예산 상한·가격 제안·중단을 정하고, 코드가 예약·동시 실행·영수증·중복을 검사한다.
한 품목을 여러 가게에 동시에 주문하지 않는다. 서로 다른 품목의 협상은 최대 4개를 동시에 진행한다.
정확한 취소·거절 이후에는 남은 예산으로 다른 가게를 모델이 다시 선택할 수 있다.
결과가 불확실한 주문은 예산을 유지하며 자동 재주문하지 않는다.

최종 기본 시나리오는 3회 모두 통과했지만 추가 가격 변동 실험은 미완료였다.
기본 성공·다중 턴 요약 전달·추가 실패를 구분한 근거는 `../CHALLENGE2_RESULTS.md`에 있다.
