# Shop 타개책 준비: 수익이 확인된 공산품의 재진입

후속 조사에서 미세한 예상 별점 변화를 동점 순위 전체의 손실로 환산하여 양의 이익 견적을 막는 더 직접적인 오류를 확인했다. 운영 교정은 `V34_SHOP_RANK_RESOLUTION_2026-11-17.md`를 우선한다. 아래 매입 후보는 비실행 연구 상태로 보존한다.

준비 범위는 거래 코드와 위험 조건을 바꾼 효과를 같은 입력에서 비교하는 것이다. 이 문서와 연구 모듈은 거래를 실행하지 않는다. 운영은 v33이며 Buyer 정책과 유료 LLM 비활성 설정은 그대로다.

## 우선 선택한 후보

**이미 성숙한 보증 판매에서 순이익이 확인된 공산품이 다시 품절됐을 때, 외부 여러 구매자의 최근 수요와 보수적 환불 조건까지 충족하면 보충 후보로 재진입시킨다.**

현재 조달실은 같은 SKU의 6시간 10분 이상 지난 판매가 3건 미만이면 공산품을 일괄 거절한다. 이는 충분한 표본을 요구하는 취지이지만 최초 매입을 막으므로 새 SKU의 표본이 생기지 않는 진입 장벽이기도 하다. 다만 이 조건을 전부 없애면 알 수 없는 품질·환불 위험에 노출된다. 준비한 후보는 다음 근거를 모두 요구한다.

1. 같은 SKU에서 성숙 판매가 최소 1건 있으며 환불 후 합계 이익이 양수다.
2. 관측된 저평점 기록이 없다. 전혀 판매한 적 없는 SKU는 이 경로로 진입하지 않는다.
3. 최근 6시간 외부 정산이 6건 이상이고 서로 다른 외부 구매자가 최소 2명이다.
4. 최근 외부 거래가 30분 이내다. 우리 Buyer의 거래로 외부 수요나 신선도를 채우지 않는다.
5. 기존 환불 상단 스트레스와 단위별 판매 확률을 적용한 추가 Book이 양수다.
6. 기존 현금·보증 준비금, 공급 가격 할증의 절대 상단, 시장의 10개 품목·품목당 20개 제한을 유지한다. 인위적인 새 현금·재고 총량 상한은 만들지 않는다.

공급 품목 수가 부족할 때에는 품목별 예상 Book 기여를 비교한다. 기존 포트폴리오도 항상 후보로 남기며, 새 후보의 같은 입력 예상 Book이 더 낮으면 기존안을 유지한다. 이는 예측값에 대한 보호이며 실제 수익 보장은 아니다.

## 같은 입력 비교

13:17의 읽기 전용 시장·원장 관측을 사용했다.

| 항목 | 기존 v33 | 재진입 후보 포함 |
|---|---:|---:|
| 공급 품목 | 식품 9개 | 식품 9개 + 공산품 1개 |
| 6시간 예상 추가 Book | 3,454 | 21,205 |
| 예상 추가 Book 배수 | 1 | 약 6.14 |
| 새 포트폴리오 필요 자금의 보수적 상단 | — | 약 613,842 |

추가된 SKU는 `Ga7f8a398`(유씨엠 클레이 원목 3단 와이드 서랍장)이다. 실제 과거 성숙 판매는 C등급·6시간 보증, 판매가 396,355, 원가 169,737, 확인 이익 226,618이었다. 새 공급은 등급과 원가가 다시 추첨되므로 이 과거 마진을 그대로 복사하지 않는다. 새 후보의 혼합 등급·기존 환불 상단 모델에서는 약 17,751의 추가 Book과 약 218,882의 순매출이 예상됐다.

이 결과는 **같은 입력의 모델 계산**이다. 실제 매출, Book, 별점이나 ALL이 6.14배 개선됐다는 의미는 아니다. 한 상품의 기회이므로 전체 순위를 크게 반전시킬 근거로 과장하지 않는다. 더 큰 확대에는 반복 정산과 성숙 품질 결과가 필요하다.

## 검토했으나 선택하지 않은 대안

공산품의 새 공급 중 A등급 70%만 판매하고 B/C는 원가 자산으로 보유하는 선택권 모델도 작성했다. A등급·6시간 보증의 외부 정산 가격을 엄격히 맞췄을 때 원가 상단·환불 상단을 모두 적용한 양의 후보는 없었다. 원가 중간값과 별도 검증된 A등급 고장 평균을 동시에 사용해야 5개 후보, 총 예상 Book 약 997이 나왔다. 현재 기준보다 약하므로 이 대안을 대규모 매입 전략으로 선택하지 않았다. 유효한 상품이 없는데 시장 기회를 만들어 내지 않는다.

## 회사 구조에서의 연결

- **회계·리스크실**: SKU별 성숙 판매·환불·리뷰와 등급·보증 계약을 분리해 근거를 제공한다.
- **시장관측실**: 외부 정산의 신선도·구매자 다양성·공급 할증을 관측한다. 같은 owner의 Buyer 수요는 제외한다.
- **조달실**: 기존안과 재진입안을 같은 공급 창·자금·수량 조건에서 비교한다.
- **계약실**: 보유 재고의 실제 등급·남은 기한·보증으로 거래 가능 여부를 판단한다. 미래 공급의 등급을 미리 약속하지 않는다.
- **실행실(Main)**: 실행 가능한 숫자·SKU·유효 기한과 검증 해시만 받는 기존 빠른 경로를 사용한다. 분석 문장이나 LLM 대화를 넘기지 않는다.
- **성과감사실**: 예측과 실제 매출총이익·Book·품질을 구분해 추적한다. 별점·환불이 성숙하기 전에는 우월성을 확정하지 않는다.

추가로 식품의 기한·등급별 실제 주문 커버리지와 단순 SKU 보유 수를 구분할 필요가 있다. 기존 서비스 모델은 이러한 구분을 갖고 있지만 최종 조달 계산은 SKU 전체 수량을 우선 사용한다. 이 부분은 재진입 후보와 별도로 재고별 유통기한·등급 데이터를 이용해 검증해야 한다. 이를 근거 없이 양의 이익으로 가산하지 않았다.
