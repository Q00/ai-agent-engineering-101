# v27: 수요가 확인된 상품의 구색·비축량을 포트폴리오로 결정

## 문제와 변경

상위 가게의 수량이나 공산품 비중을 목표로 고정하지 않는다. 외부 정산·우리 가게의 노출 중 유료 판매·현재 재고·가격·공급 할증으로 추가 매입의 Book과 매출 기여를 계산한다. 단순히 현금을 재고로 바꾸는 것은 Book 증가로 계산하지 않는다.

기존에는 공통 보충기간 배수가 작으면 수익성이 있는 추가 수량도 후보 생성 전에 제외됐다. 새 정책은 자체 수익성 있는 판매 3건 이상, 또는 최근의 외부 정산 20건·서로 다른 외부 구매자 3명 이상이 확인된 상품에 대해 법정 한 로트의 1~20개를 비교한다. 기존 보유량을 수요에서 먼저 차감하므로 여러 공급 창에서 같은 수요를 무한히 반복 계산하지 않는다. 총재고·SKU 보유량의 선택적 상한은 다시 도입하지 않았다.

개별 상품의 가장 높은 투자수익률보다, 제한된 공급 호출 한 번으로 얻는 로트 전체의 목적함수 기여를 비교한다. 6시간 이내의 기존 수요 전망에서 수량별 예상 Book·매출, 실제 재고 원가 제거, 환불, 저장, 식품 만료를 함께 반영한다. 품질·원가가 불확실한 신규 품목에 큰 수요를 임의로 부여하지 않는다.

식품의 추가 비축은 카탈로그 보관 기간의 45%가 평가 기간보다 긴 경우에만 확대한다. 이는 A·B 공급 등급까지 대규모로 만료될 수 있는 상황에 기존 25% 만료 시나리오를 무리하게 전용하지 않기 위한 조건이다. 실제 사용 기간·등급 요구의 v26 재고 선택과 보증 의무는 유지한다.

## 선택과 자동 개선

1. 같은 최신 자료에서 기존 정책의 매입안을 다시 만든다. 재생에서는 기존 v26 실행 결과와 수량·자금·예상 Book·매출이 일치하는지 검증한다.
2. 기존안에 악화 시나리오에서도 이익이 남는 수량을 추가한 안, 그리고 구색·비축량을 재구성한 여러 로트 포트폴리오를 만든다.
3. 시장의 실제 Book·매출 순위 간격으로 로트의 기여를 평가한다. 악화 시나리오에서는 공급 등급 혼합의 원가 상단과 관측 근거에 따른 낮은 수요를 적용한다. 이는 공학적 민감도 분석이며 통계적 신뢰구간이나 손실 보장이 아니다.
4. 포트폴리오 단위의 악화 성과를 기존안 이상으로 유지하는 조합을 탐색한다. 개별 SKU마다 최악 조건 이익을 강제해 모든 공산품을 배제하거나, 전체 포트폴리오의 위험을 무시해 수량만 늘리는 방식으로 고정하지 않는다.
5. 기존안보다 예상 Book·순위 기여가 낮거나 악화 시나리오의 Book이 더 나쁘면 선택하지 않는다. 조건을 충족하는 대안이 없으면 기존안을 유지한다.

최적화는 추가 LLM 없이 기존 사전 매입 계획과 숫자 실행기에 연결한다. 새 재고 관찰 역할은 기존 60초 배경 주기에서 수요 모델과 포트폴리오 비교 결과를 추적한다. 기존 Analyst/Critic에는 만료와 규칙 해시를 확인한 작은 요약만 전달한다. 전체 원시 대화와 모든 매입 후보를 LLM 컨텍스트에 복제하지 않는다.

기존 현금·보증·저장 준비금, 공급 시간·한 번당 수량·호출 수 제한, 공급 중복 실행 방지와 인증·결제 경로는 유지한다. Buyer 전략·품질 성숙 시계와 모델 구성은 변경하지 않는다. Astra는 제외하고, 새 유료 역할과 Main LLM 호출은 추가하지 않는다.

## 검증의 의미

초기 개발 재생에서는 22개→97개, 예상 Book 약 7.16만→33.77만인 조합이 선택됐다. 다른 시점에서는 18개→103개이고 공산품 11개를 포함했다. 이들은 서로 다른 개발 시점의 전망이며 실현 수익이나 동일한 최종 소스의 성과 비교로 사용하지 않는다. 최종 배포 근거는 해시가 일치하는 재생과 전체 회귀검사 로그로 구분한다.

현재 시장에서 무조건 1·2위를 추월한다는 검증은 불가능하다. 이후 실제 공급, 정산 Book 증가, 매출, 계정 단위 리뷰, 환불·폐기를 함께 관측해야 한다. 수요 감소·공급 할증·경쟁 가격 변화가 발생하면 같은 계산을 새 자료로 반복하고, 확대할 근거가 사라지면 추가 매입을 줄이거나 기존안을 선택한다.
