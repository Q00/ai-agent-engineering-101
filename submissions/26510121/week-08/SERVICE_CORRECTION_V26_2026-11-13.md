# Shop 별점 · Buyer 구매 완결 교정 v26

## 교정 범위

직전 조사에서 확인한 병목을 실행 코드에 연결한다. 원시 거래·리뷰·실패 기록은 수정하지 않는다. 목적은 공식 Shop ALL·Buyer ALL 개선이며, 매출·구매 건수만 높이는 정책으로 바꾸지 않는다.

### Shop

- 요청의 사용 기간·등급·최소 보증을 정규화하고 협상 후속 메시지에도 적용한다. 조건이 강화되면 실제 재고를 다시 검사하고, 가능한 경우 새 단위를 예약한다. 교체한 단위의 실제 원가도 함께 갱신한다.
- 견적과 영수증을 발행하기 전에 조건을 다시 검사한다. 이미 발행한 영수증 재요청은 기존 멱등 경로를 유지한다.
- 명시된 등급 선택 범위가 있을 때, 짧은 사용 기간 주문에 희소한 장기 보관 재고를 먼저 소모하지 않는 선택을 추가한다. 등급 선호가 없으면 기존 품질 우선 선택을 유지한다.
- 전체 수량 외에 사용 조건을 만족하는 재고의 부족을 보충 후보로 만든다. 실매출 2건 이상·서로 다른 3분 이상 관측을 요구하고 익명 요청은 분 단위로 축소한다. 명시된 조건의 비중을 전체 수요로 확대하지 않는다.
- 새 공급에서 조건을 만족할 확률과 선택된 재고의 높은 원가를 반영한다. 추가 수량별 예상 Book이 양수인 경우만 투자한다. 적합 재고를 얻기 어렵다는 이유로 손해 매입을 강제하지 않는다.
- 재고나 조건 모델이 바뀌거나 사용 기한·등급 경계를 넘으면 사전 매입 계획을 폐기하고 다시 계산한다.

### Buyer

- RFQ 두 경로의 견적 점수에 최신 margin-share Saved 공식과 원가 시나리오를 전달한다.
- 선택된 공산품 견적이 불완전하면 같은 협상 작업에서 최대 1회·2초로 실제 가격·등급·보증을 확인한다. RFQ 경쟁 응답마다 추가 확인을 기다리지 않는다. 타임아웃 시 원래 견적을 유지하며 인증·결제 검증은 계속 적용한다.
- 현재 Saved 부근·다음 공개 Saved 기준·호가의 97%/99%도 제안 후보로 비교한다. 이 기준은 구매 상한이 아니며 전체 목적함수와 예산·계약 조건이 최종 행동을 결정한다.
- 협상 학습을 주문·판매자·SKU·작업 ID·정산 가격으로 연결한다. 다른 상품 구매를 첫 제안 성공으로 기록하지 않는다. 통신 실패는 가격 거절로 학습하지 않는다.
- 첫 제안의 가격으로 최종 보상을 계산하지 않고 전체 협상의 완료 확률·최종 가격·소요 시간을 관찰한다. 시간순 별도 검증을 통과한 모델만 행동에 사용하고, 미달 시 그림자 평가로 돌아간다. 이 모델은 현재 정책 아래의 관측 시나리오이며 판매자의 인과적 수락 확률이 아니다.
- 하위 관찰기는 60초 주기로 조건별 수요와 완결 가능한 계약을 갱신한다. Main은 만료·규칙 해시를 검사한 숫자 패킷을 사용한다. 관측 결과를 기존 LLM 분석·독립 검토에 간결하게 전달하며 추가 LLM 호출은 만들지 않는다.
