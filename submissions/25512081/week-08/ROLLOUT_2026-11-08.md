# 2026-11-08: shop 품질 개선 절차의 운영 반영

server-53의 운영 코드와 로컬 코드를 맞추고 변경 단위로 커밋했다. 기존 이력과 로그는 유지했다.
이 배포에서 Claude를 호출한 비교 실험은 하지 않았다. 공유 주간 한도 소진 중이므로 모델별
선택 품질이나 시장 성능이 좋아졌다는 결론을 내리지 않는다.

## 반영한 것

- 모델 없이 공개 ledger를 증분 수집하는 `shop_metrics.py`: 초기 60,000건에서 우리 정산 후기
  274건을 연결했고, 이후 5분마다 추가 관측한다. 원시 관측과 점수 스냅샷은 새 로그에 추가한다.
  평가자 계정을 합쳐 집계하고, 가격·등급·보증·유통기한 불만과 재고를 분석한다.
  수집 범위·미수집 backlog를 표시하며 이 값은 누적 stars_rank의 복원이 아니다.
- 40분·2시간 Book/매출/정산 증감과 관측 별점 비교. 과거 스냅샷이 충분히 쌓이기 전에는
  baseline_ready=false와 null 증감을 반환한다. 비교 기간을 임의로 만들어 내지 않는다.
- 식품의 명시적 요구 기간은 견적과 서명 직전에 확인한다. 결제 여유는 1분이다. 짧은 재고로
  대체하지 않는다. 기간을 말하지 않은 주문에는 기존 신선도 추정을 유지하므로 숨겨진 요구를
  보장할 수 없다. 충분한 기간을 충족하는 C등급 식품은 계속 판매한다.
- 카테고리 주문은 영수증의 item도 그 카테고리로 유지한다. 명시한 SKU/상품은 SKU가 우선이며,
  실제 배송 unit과 ACP checkout의 SKU 바인딩은 유지한다. 시장 계약에서 허용한 두 표현을 사용한다.
- planner의 MCP `shop_quality` 도구와 목표를 현재 Class/Book/계정별 별점 규칙에 맞췄다.
  마감만을 이유로 원가 이하 덤핑하거나 마지막 24시간의 사입을 일괄 중단하는 규칙을 제거했다.
- 서버의 OVERSEER.md는 버전 관리되는 OPERATIONS.md를 먼저 읽도록 했다. 이전 지침 원문은
  별도 로그에 보존했다. 비교 표본이 부족하면 가격을 유지하고 추가 관측하도록 명시했다.

## 관측으로 유지하기로 한 것

초기 연결 후기에서 식품 A/B/C 평균은 각각 4.80/4.70/4.14이고, 유통기한 부족 불만은 4건이었다.
그러나 가격 구간과 별점 사이에 일관된 단조 관계는 없었으므로 일괄 할인은 하지 않았다.
등급 효과에는 평가자·상품 구성 차이가 섞여 있다. 특정 평가자의 낮은 점수만으로 상품 등급을
원인으로 단정하지 않는다. 카테고리 영수증을 잘못된 상품으로 오해한 1점 사례도 확인됐다.

사입 대안은 shadow_alternatives로만 제시한다. 혼합 등급과 추정 원가를 쓴 계산이므로 자동
매입 지시가 아니다. OPERATIONS.md에 비교 근거가 있을 때 한 카테고리의 가격을 0.02만 조정하거나,
대체 SKU 하나를 1~2개로 시험하고 두 공급 주기 이상 확인하는 절차를 기록했다.
예외 협상 Sonnet, planner/overseer Opus는 유지한다. 후보 선택 Haiku 변경도 유지한다.

## 검증과 배포

- 운영 Python으로 변경 파일 구문 검사, 격리된 사본에서 회귀 검사 9개 통과.
- 서명된 카테고리 영수증을 실제 kit의 AcpShop.create에 넣어 배송 SKU와 unit이 유지됨을 확인.
  합성 키와 가짜 inventory 응답만 사용했고 실제 시장에 테스트 거래를 보내지 않았다.
- MCP 도구가 수집 근거를 반환하고 Book에 재고 원가가 포함됨을 격리 사본에서 확인.
- 공급 창이 닫힌 뒤 정확한 kit/seller PID만 종료하고 keepalive 재기동을 확인했다.
  이전 kit/seller 26206/26209 → 새 kit/seller 10880/10883.
- 새 터널의 A2A card와 ACP descriptor가 모두 HTTP 200, 시장 재등록 확인.
- 새 프로세스 이후 실제 정산 ledger #3782773, G010744b7, 19,340 크레딧 확인.
- 로컬/서버의 변경 소스 7개 SHA-256 일치 확인. push/PR 제출은 하지 않았다.

가격·재고 실험의 성과, 별점 4.40 달성, 1위 추격은 아직 검증 결과가 아니다.
이 배포는 관측과 명확한 거래 품질/목표 오류 수정 단계이며, 이후 자동 보고에서 표본과 결과를 비교한다.
