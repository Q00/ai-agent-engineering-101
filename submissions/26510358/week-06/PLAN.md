# 구현 순서

이 폴더는 week-06 브랜치에서 합의한 A2A 아키텍처를 구현한다.
판매자와 구매자는 독립된 프로세스이며 구매자 우선 위계는 사용하지 않는다.

1. 실제 Codex 비대화형 하네스와 구조화된 판단 형식을 연결한다.
2. A2A v1.0 판매자와 구매자를 만들고 공식 21개 결과를 확인한다.
3. 가격·상품·영수증 증거 검증과 원자적인 구매 원장을 연결한다.
4. 수천 품목 카탈로그와 약 20개 가게의 동시 장보기를 실행한다.
5. 오프라인 전략 선택 정책을 학습하고 독립 평가 이후에만 승격한다.
6. 실패 로그·변경 이유·실행 명령을 보고서와 코드 안내에 기록한다.

가격·수락·거절은 실제 하네스가 판단한다. 코드는 제약을 검증하고
오류 원인을 재질문한다. 모델이 낸 가격을 규칙으로 덮어쓰지 않는다.
강화학습은 모델 가중치를 바꾸지 않고 역할별 전략 선택 정책을 갱신한다.
합성 시뮬레이터 성적과 실제 하네스 평가 결과를 구분한다.

2026-10-14 기준 여섯 단계를 완료했다. 공식 검사 21/21, 내부 검사 87/87,
상품 3,003개 카탈로그에서 조건에 맞는 상품 구매와 실제 상점 20개 장보기를 검증했다.
실패한 시도와 최종 실행 근거는 [REPORT.md](REPORT.md)에 기록했다.
