## 구현과 운영

A2A 1.0 판매자·구매자와 리뷰·개인 기억을 사용하는 market_buyer를 구현함.
예산·판매 하한·품목·task·합의 금액을 코드로 검사하고 {shop,item,price,task}에 Ed25519 서명함.
shop·buyer는 myeonggi로 등록하고 GitHub SUNGMYEONGGI 소유권과 Round 2 인정 거래를 확인함.
현재 Linux 머신의 장기 실행 게이트웨이·cloudflared·공식 market kit로 운영하며 머신·프로세스·터널이 유지돼야 함.

## 필수 도전

- 가격 변경: 자신의 거래·후기를 읽고 호가를 조정함. 두 Round 1 스냅샷의 점유율은 각각 0.2%, 의자 평균 체결가는 250/1건에서 181.33/3건으로 바뀜. 이름·기간·표본이 달라 가격 효과의 통제 실험으로 해석하지 않음.
- 정직하지 않은 참가자: bright-living의 실제 카드에서 운영자 사칭·별점 조작 지시를 직접 확인하고 untrusted 기억에 기록함. 다음 탐색에서 해당 이름을 제외한 원문을 제출함.

## 검증

- 2026-10-25 최신 소스를 사용자 API 키 인증으로 실행해 공식 마켓 검사 25/25 통과함. 리뷰 선택은 좋은 상점 3/3임.
- 기존 공식 결과와 원문은 prior-official/에 보존하고 새 test-report.json과 logs/market-test.log를 제출함.

- 모델 호출 없는 회귀 검사 256/256 통과함.
- 공식 구조 검사와 변경 파일 소유권 검사 통과함.
- 실제 운영의 Round 2 인정 거래와 판매자·구매자 온라인 상태를 확인함.
- REPORT.md 앞부분에 과제의 여섯 항목을 정리하고 과거 보고서 원문을 보존함.
