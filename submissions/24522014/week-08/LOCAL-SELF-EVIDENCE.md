# 자기 가게 평가는 로컬 확정 정산으로

공개 ledger의 제한된 표본에 자기 가게 거래가 빠져 자율 실험이 시작되지 않는 문제를 보완했다. 실험의 최소 표본 조건을 낮추지 않고 평가 자료를 바꿨다. 현재 적용 출처는 `local_acp_v1`이다.

## 자료의 역할

| 자료 | 사용 목적 |
|---|---|
| 내 kit의 `[acp] settled` 원본 로그 | 자기 확정 정산 수·매출·거래 시각·unit·실제 등급 |
| 같은 unit의 서명 제안·pricing 기록 | SKU·실제 매입 원가·보증·실험 ID 연결 |
| 공개 R3 정산 표본 | 같은 SKU·등급·보증 조건의 시장 가격 비교 |
| 공식 board | 표시 별점·후기·방문·Players 순위 등 공식 지표 |
| 공개 환불 사건 | 이미 확인된 자기 unit의 사후 위험을 보수적으로 경고하는 보조 근거 |

공개 정산을 자기 실험 거래 수에 더하지 않는다. 서명만 했거나 결제가 거절된 제안, buyer 결제 로그, 모델이 출력한 가짜 ACP 문구도 자기 판매 정산으로 세지 않는다. 실제 kit가 시장 정산 성공 후 직접 기록한 행만 사용한다.

## 로컬 인덱스

`local_settlements.py`가 `logs/market-kit.log`를 읽어 `.market/local-settlements.json`에 인덱스를 저장한다. 원본 로그는 수정하지 않는다. 첫 실행에는 R3 등록 이후를 복원하고, 이후에는 저장한 byte offset부터 완결된 줄만 추가로 읽는다.

- ledger ID로 중복 제거하며 같은 ledger의 unit·금액·등급이 충돌하면 정상 자료로 사용하지 않는다.
- 날짜 없는 로그는 파일 스냅샷의 시각과 자정 경과로 복원한다. R3 시작 등록이 확인돼야 한다.
- 재시작·반복 행·부분 쓰기와 로그 교체를 처리한다. 이전에 확인한 정산 이력은 보존한다.
- 읽기 시작 시점의 파일 크기까지만 읽어 동시 append와 섞이지 않게 한다.
- 원가·SKU가 확인되지 않은 거래는 누적 정산 수에는 남기되 원가 기반 실험 그룹에서 제외한다.
- 같은 금액의 여러 서명 제안 때문에 실험 ID가 모호하면 해당 거래로 실험 효과를 입증하지 않는다.

제어기의 기존 OS writer lock 안에서 인덱스를 갱신한다. 별도 네트워크·LLM 호출이 없다. 로컬 로그가 오래됐거나 R3 출처·내용에 문제가 있으면 공개 표본으로 자기 실적을 대신 채우지 않는다.

## 기존 기준선과 실험

제어기 이력의 정산 수·매출을 각 관측 시각까지의 로컬 확정 거래로 다시 맞춘다. 기존 관측 시각과 현금·원가 기반 운영 값·별점은 보존한다. 자료 출처가 다른 채 진행 중인 실험이 있다면 먼저 이전 정책으로 복원해 두 자료 정의를 섞지 않는다. 이번 실제 전환 시점에는 진행 중 실험이 없었다.

가격 비교는 새 재고 unit이라도 같은 SKU·등급·무보증의 공개 가격 그룹을 찾을 수 있다. 같은 상품의 오래된 unit ID에 묶여 시장 가격을 놓치지 않도록 했다. 등급·보증이 다른 비교값은 사용하지 않는다.

진단 후보에는 로컬 기준선의 자기 정산 수와 자료 출처를 기록한다. 대기 사유도 `no_eligible_market_candidate`와 `insufficient_local_same_condition_settlements`로 구분한다. 최소 2시간·새 정산 10건·같은 조건의 자기 정산 3건, ±3% 변경 범위와 현금·품질 보호 조건은 그대로다.

## 실제 확인

2026-11-04 09:51 KST에 로컬 확정 정산 **176건**, 매출 **17,639,116원**, 원가 연결 **176건**, 누락 metadata **0건**, 충돌 **0건**을 확인했다. 공개 표본에는 자기 정산이 47건만 있었다. board 캐시의 169건은 더 이른 관측으로 시각이 다르다. 기록은 `logs/local-self-evidence/20261104T005116447651Z.json`이다.

09:52 제어기의 `self_evidence_migrated` 기록을 확인했고, 이후 실제 진단도 local_acp_v1을 사용했다. 마지막 확인 상태는 `waiting_for_comparable_evidence`, 세부 사유는 `no_eligible_market_candidate`다. 자료 누락을 없앴다는 검증이며, 새 실험이 완료돼 성과가 개선됐다는 뜻은 아니다. 실제 상태는 `logs/local-self-evidence-live-status-final.log`에 있다.

09:27 관측 시점으로 잘라 공식 board와 건수·매출을 대조한 별도 기록은 `logs/local-self-evidence/board-cutoff-reconciliation-20261104.json`에 남겼다. 과거 시각의 기록을 복원해 현재 로컬 집계와 더 이른 board 캐시를 혼동하지 않도록 했다.

전체 오프라인 **168개 검사 통과**: `logs/local-self-evidence-all-tests-final.log`. 자정·재시작·중복·부분 쓰기·충돌·R2 제외, 공개 누락 시 로컬 거래 사용, 공개 거래만으로 자기 실적 생성 금지, 시장 가격 비교 유지, 기준선 전환·기존 실험 복원, 새 unit 비교와 최소 표본 유지 등을 검증했다.

실행 중인 restock 훅이 새 제어기 모듈을 읽으므로 **키트 재시작이 필요 없다.** 이전 요청에 따라 커밋은 보류했다.
