# W07 가게 선택 대조 실험: 첫 결과

## 조건과 재현

`compare_reputation.py`는 실제 시장이나 LLM에 접근하지 않고 현재 `../week-07/buyer_memory.py`의 `choose_shop`을 합성 입력으로 호출한다. 품목 lamp, 예산 120, 시각 2026-10-20 12:00 UTC, 후보 두 곳과 기록 수 1건을 사용한다. 기록 수를 고정해 5번째 주문 순환 탐색을 비활성화했다. 과거 성공 구매와 연결 오류는 없다. 기준·후기 조건에서는 다른 가게의 단순 결렬을, 불일치·결렬 조건에서는 대상 가게의 기록을 사용한다. 그러므로 기록의 가게와 유형이 함께 달라지며, 결과는 이 구체적인 설정에서의 비교다.

저장소 루트에서 다음 한 줄로 같은 JSON을 출력한다. 표본은 각 조건과 이름 순서 조합당 1회로, 결정적 함수의 동작 확인이지 무작위 반복 실험이 아니다.

```powershell
python submissions/24522014/week-08/compare_reputation.py
```

실행 기록: `logs/reputation-comparison-20261102.json`.

|---|---|---|---|---|

| 단순 결렬 | 대상 선택 | 상대 선택 | 아니요 | 아니요 |

## 해석과 한계

직접 불일치는 대상 가게를 제외했고, 서로 다른 경고 후기 2건은 차단하지 않고 우선순위를 낮췄다. 동일 후기 반복과 단순 결렬은 이 입력에서 경고나 차단을 만들지 않았다. 대상 이름이 뒤일 때 기준 조건부터 상대가 선택돼, 비선택만으로 경고의 효과를 알 수 없으며 근거 필드를 함께 봐야 한다.

이는 결정적 선택 함수의 제한된 합성 입력에 대한 결과다. 후기 문구와 언어에 따른 탐지 누락, 직접 불일치 기록의 진위, 다른 위험 조합, 5번째 순환 탐색, 실제 거래 성공률을 평가하지 않았다. 기존 maple-home 사건은 `../week-07/CHALLENGE2-AUDIT.md`에 있는 별도 관찰 사례이며, 이 실험은 그 사건 이후의 회피 원인을 증명하지 않는다. LLM은 이 실험에서 호출되지 않았다.
