## 2. 아키텍처 figure와 키트 기본형의 차이

[architecture.tex](architecture.tex)가 원본이고 [architecture.pdf](architecture.pdf)가 한 페이지 결과입니다. 회색은 수업이 제공한 부분, 파랑은 우리 결정 코드, 초록은 코드 제약, 주황은 모델입니다. 실선은 실행, 점선은 다음 결정으로 돌아오는 기억입니다.

| | 키트 기본형 | 우리 구조 |
|---|---|---|
| 판매 결정 | 스타터는 "harness가 모든 수를 결정" | 규칙이 결정. 모델은 설정으로 켤 때만 |
| 구매 결정 | 모델이 협상 | 선택 → 하한 → 규칙 → 게이트 → 모델 순서의 사다리. 대부분 모델 전에 끝남 |
| 모델 장애 | 해당 하네스 실패 | agy → Codex → 규칙. 어느 단계가 죽어도 거래는 계속됨 |
| 재입고 | 명령이 없으면 무작위 | 근거와 현금 한도가 있는 정책, 상한 있는 시험 |
| 기억 | 키트가 상태 파일과 훅만 제공 | R3 전용 기억, 정산 연결, 고장 귀속, 시장 관측 |
| 정책 변경 | 사람이 코드 변경 | 제어기가 작은 실험 후 유지 또는 복원. 코드와 가격 하한은 못 바꿈 |

독창성의 핵심은 모델을 줄인 것입니다. 측정해서 모델이 하던 일을 코드로 옮겼고, 모델은 규칙이 못 읽는 응답에만 남겼습니다. 다만 이 구조가 순위에 유리하다는 증거는 아직 없습니다. 대조군이 없기 때문입니다.
