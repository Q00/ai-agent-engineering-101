# Top 3를 관측하고 검증 가능한 부분을 전략에 반영하기

**목표 변경:** 현재 `leader_monitor.json`의 기준은 `shop_profit`, 목표는 seller 순이익 1위다. 아래 Players Top 3 설명과 13:41 결과는 최초 구현 이력이다. 현재 전략·적용 범위는 [순이익 1위 전략](PROFIT-FIRST-STRATEGY.md)을 따른다. 목표 변경 시 기존 목적의 실험을 종료하며 거래량 증가만으로 시간당 차익 감소를 허용하지 않는다.

## 목적과 실행

`leader_monitor.py`는 **30분마다** 공개 대시보드 `/api/board?round=3`를 조회한다. Players의 공식 `total` 순위로 Top 3를 매번 다시 선택한다. 수집·분석은 Python 규칙이며 LLM을 호출하지 않는다. 추가 공개 API 요청은 정상 주기 기준 하루 최대 48회다. 포럼 5분 수집·30분 분석 주기는 그대로 유지한다.

실행 중인 키트의 매분 restock 훅에 연결했으므로 재시작이 필요 없다. 분석과 가격 후보 생성은 자료가 있을 때 진행하며, 직접 매입·거래하거나 다른 가게에 메시지를 보내지 않는다. 네트워크 실패·불완전 순위·오래된 분석은 해당 벤치마크 사용을 중단하고 기존 판단으로 돌아간다.

## 분석하는 것

- **순위와 격차:** 공식 total·shop ALL·buyer ALL, 내 순위와 3위 점수 차이. 2시간 이상 자료가 쌓이면 동일 참가자의 점수 변화도 기록한다.
- **판매자 실적:** 순이익·매출·정산 수·방문·별점·환불·파산. 공개 정산 표본에서는 판매 카테고리·SKU·가격·등급·보증 분포를 요약한다.
- **순이익 선두:** 종합 Top 3와 별개로 shop 순이익 Top 3를 함께 기록한다. 13:47 KST 별도 조회에서는 dae-yangkim이 순이익 66,605,502로 1위였다. 이 목록을 종합 순위로 혼동하거나 가격 실험 근거로 자동 대체하지 않는다.
- **구매자 실적:** 잉여·정산 수·forum 지표·글 수와 관측 구매 품목을 비교한다.
- **포럼:** 수집된 해당 참가자의 글 수와 좋아요·나빠요를 관측한다. 글의 주장은 검증한 정책으로 취급하지 않는다.

한 계정에 가게가 여러 개면 Players의 점수에 연결된 이름과 owner가 모두 일치하는 행만 사용한다. 소유자 없는 기본 에이전트도 공식 순위에 포함하되 참가자 이름으로 구별한다. 가게 이름·URL이 모호하면 거래를 귀속하지 않는다. 같은 계정·가게의 이전 터널 URL은 최대 24시간 참고하며, 여러 계정에 중복된 URL은 제외한다.

공개 ledger는 제한된 표본이다. 관측 건수는 실제 전체 판매량·시장 점유율이 아니며, 원가·프롬프트·내부 판단·비공개 정책은 알 수 없다. 원시 지표의 Top 3 중앙값과 차이는 진단용으로만 표시하고 공식 ALL 계산으로 재해석하지 않는다.

## 실제 반영 경로

1. **가격 실험:** 최근 6시간 Top 3 판매 중 같은 SKU·등급(A/B)·보증 0시간의 비식품 정산이 3건 이상, 구매자가 2명 이상일 때 중앙값을 비교한다. 현재 재고가 해당 조건과 일치하고 전체 시장 비교와 조정 방향이 충돌하지 않으면 가격 실험 후보로 연결한다. 이 후보를 기존 일반 시장 후보보다 우선 검토한다.
2. **기존 실험 보호 유지:** 조정 폭은 한 번에 최대 3%, 누적 배수 0.94~1.03, 하루 실험 2회 이하다. 내 동일 조건 확정 정산 표본과 기준선이 부족하면 시작하지 않는다. 2시간 시험·6시간 성숙 대기·자기 정산 평가·악화 시 복원을 그대로 적용한다. 이미 진행 중인 실험을 덮어쓰지 않는다.
3. **매입 보조 신호:** Top 3 실판매와 시장의 서로 다른 구매자 3명 이상이 관측되고, 정가 대비 최대 매입 원가 75% 및 하루 보관비를 고려한 보수적 차익 추정이 양수인 상품만 매입 후보로 요약한다. 기존 수요 검증·수익성·자기 판매 근거가 같은 후보끼리만 보조 우선순위를 부여한다. 실제 매입 가격과 판매 결과를 보장하지 않으며 기존 현금·재고·미검증 상품 한도와 식품 보류 조건을 유지한다.

상위권의 낮은 가격·높은 글 수·보증 제공을 그대로 복제하지 않는다. 자기 가게 평가에는 계속 **로컬 ACP 확정 정산**을 쓰고 공개 ledger는 외부 비교에 사용한다. buyer 예산·품질·안전 조건은 바꾸지 않는다.

## 기록 위치

- `.market/leader-intel.json`: 최신 Top 3·실적 격차·거래 표본·가격 비교·매입 보조 후보·추이.
- `logs/leader-monitor/`: 매 관측 결과를 새 JSON으로 보존.
- `logs/strategy-controller/`: 진단·실험에 `leader_benchmark`, `benchmark_source`, 참가자와 ledger 근거 연결.
- `logs/restock/`: 사용한 `leader_hints`와 기존 예산·매입 판단 근거.
