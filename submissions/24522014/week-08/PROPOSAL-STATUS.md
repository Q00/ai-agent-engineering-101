# R3 전략: 적용 여부 점검

**최신 상태(11월 4일):** 승인 1~5번을 [SHOP·BUYER 균형 전략](BALANCED-STRATEGY.md)으로 구현했다. 목표는 Players 종합 Top 3, buyer는 하루 480회 이내 유리한 거래 시도/모델 협상 하루 24개 주문·시간당 2개, buyer 포럼 최대 12개다. 후기 귀속·만족도 보충·A등급 2시간 보증 소량 실험·공식 ALL 평가를 추가했다. 상주 seller 영수증·보증은 재시작 후 적용된다. 아래 표의 순이익 단독/연구 buyer/보증 미적용은 변경 전 이력이다. 예산 10%, 자본 비율 배분, 전역 재고 확대 원복 등은 이번 범위에 추가하지 않았다.

11월 4일 사용자 요청으로 변경 후 2시간 유휴 대기를 제거하고 재고 확대 1단계를 적용했다. 현재 목표는 seller 순이익 1위이며 순이익 Top 3 진입을 중간 목표로 본다. 다음은 현재 R3 순이익 전략의 제안과 실제 코드 상태다.

## 이번 확대로 달라지는 계산

대량 보충 자격은 로컬 ACP 자기 정산에 unit별 SKU·실제 원가를 연결해 확인한다. 동일 unit 중복·원가/SKU 모호함·오래된 자료·차익 음수는 제외한다. 최소 6시간분 보관비를 뺀 양수 차익이며 완전한 보증 차감 순이익을 뜻하지 않는다. 공개 수요는 다른 구매자의 실제 정산에서 확인하고 포럼 언급이나 buyer 연구 구매만으로 대량 매입 자격을 만들지 않는다.

새 매입분도 7일 보관비를 예산 안에서 확보한다. 재고 3개인 SKU에 3개를 추가하는 것이 아니라 **최대 3개까지** 채운다. 공급 창·회당 예산 때문에 실제 수량이 6개보다 작을 수 있다. 근거가 약해져도 기존 재고를 즉시 폐기하지 않고 신규 보충을 줄인다.

실제 자료로 다음 공급 창을 가정한 비거래 미리보기에서 이전 한도는 2개, 새 한도는 5개를 계획했다. 같은 잔고와 5% 예산에서 원가 633,450·신규 7일 보관비 44,341.5를 확보하는 계산이었다(`logs/active-restock-live-preview.json`). 실제 공급 API를 호출한 결과와 구분한다.

이후 **16:03:45~16:04:06 KST 실제 공급 창에서 3 SKU를 2개씩 총 6개 매입**했다. 실제 매입액은 539,922, 직후 재고는 8개·현금 13,371,965였다. 원본 kit의 공급 성공 줄과 계획은 `logs/active-restock-live-supply.json` 및 `logs/restock/20261104T070345172601Z-ae18dbb2.json`에 연결했다. 매입 성공을 순이익 개선으로 간주하지 않는다.

## 대기 제거와 평가 기간의 구분

제거한 것은 변경 뒤 아무 새 정책도 검토하지 않는 2시간 유휴 제한이다. 새로운 실험의 **기준선 2시간·시험 2시간·고장/환불 성숙 확인 6시간**, 데이터·현금·표본 조건과 하루 2회 제한은 유지한다. 유휴 제한 없이 적격 후보를 바로 검토하지만 효과가 확인됐다고 즉시 채택하지는 않는다. 실행 중인 실험은 겹쳐 시작하지 않는다.

가격과 재고 모두 바뀌는 이번 운영 변경을 가격 하나의 인과 효과로 단정하지 않는다. 재고 확대를 적용했다는 사실과 순이익이 개선됐다는 결과는 별도 검증 대상이다.

검증: 전체 247개 검사 통과(`logs/active-restock-final-tests.log`). 16/3/6·미검증 2개·원가/보관비/현금·공급 창·보충 감소·로컬 근거·최근 cooldown 즉시 재검토를 확인했다. 24시간 구매자를 최근 6시간 구매자로 혼동해 대량 자격을 주지 않는 것도 검증했다. 최초 검사에서 부동소수점의 엄격 동등 비교와 과거 cooldown 기대가 실패했고 해당 기록은 보존했다.
