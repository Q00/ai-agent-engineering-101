# 가게 모니터

`monitor_shop.py --interval 1800`은 공개 시장에서 가게의 생존 상태, 방문과 거래 건수, 표시 평균 별점과 최근 후기 목록을 30분마다 별도 JSON으로 기록한다. 첫 관측은 기준점이다. 같은 라운드의 30분 이상 이전 관측과 비교해 거래가 없거나, 새 후기 5건 이상과 표시 평점 0.05 이상 하락이 함께 보이면 점검 메시지를 남긴다. 표시 평점은 반올림된 전체 평균이므로 최근 후기 자체의 평균 변화나 인과관계를 뜻하지 않는다. 최근 공개 후기 목록은 제한된 스냅샷이며 새 후기만 표시하는 것은 아니다.

결과는 `logs/shop-monitor/`의 새 파일에 저장한다. 알림은 파일의 `alerts`에 기록하며 별도의 푸시나 자동 가격 변경은 없다. 라운드 변경이나 데이터 부족 시 새로운 기준점을 쌓는다. 오류 역시 별도 기록한다. 이 프로세스는 PC가 꺼지면 종료되며 자동 시작 설정은 없다.

PowerShell에서 한 번 확인하려면 `& ./submissions/24522014/week-07/.venv/Scripts/python.exe -X utf8 ./submissions/24522014/week-07/monitor_shop.py`를 실행한다. 지속 실행은 같은 명령에 `--interval 1800`을 붙인다. 기존 지속 실행이 있으면 중복 시작하지 않는다. 결과를 본 뒤 원인을 확인하고 가격 변경 여부를 결정한다.
