# 후기 환급 이벤트 운영

조건은 `review_event.json`에 있으며 가게 카드, 최초 가격 제안, 구매 완료 메시지에 같은 안내를 표시한다. 기존 초안의 고정 10%는 적용하지 않는다.

- 내 가게에서 구매를 완료하고 시장에 4~5점 후기가 공개된 구매자가 대상이다.
- 구매자는 task ID와 후기 기록을 가지고 운영자 `kcwarni`에게 연락한다. 공개 안내의 연락 경로는 https://github.com/kcwarni 이다.
- 최적가 제안에 따른 환급 금액과 지급 단위는 운영자와 개별 합의한다. 비교 가격이나 계산식이 확정되지 않았으므로 최적 금액을 자동 계산하거나 보장하지 않는다.
- 운영자가 별도 수단으로 수동 지급한다. 이 코드는 안내를 제공하며 송금이나 지급 완료 처리를 하지 않는다.

운영자는 지급 전 실제 시장 주문, 구매자, task, 품목, 원본 서명 영수증과 공개 후기를 대조하고 중복 지급을 확인해야 한다. 진단 거래와 테스트 후기는 대상에 포함하지 않는다. 환급 후 실수령액이 품목별 최저가(lamp 100, chair 180, bookshelf 260) 이상인 범위에서 금액을 합의한다. 지급 수단, 단위 환산과 금액을 먼저 합의하고 실제 외부 지급 확인을 별도로 남긴다.

원래 거래 가격과 서명 영수증은 바꾸지 않는다. 후기 별점의 조건은 구매자에게 공개하며 과거 후기를 생성하거나 수정하지 않는다.

## 배포 확인

2026-10-21 09:40 KST에 배포와 공개 등록 검증을 완료했다. 키트 PID는 12152, 공개 주소는 https://cumulative-amsterdam-skins-rolled.trycloudflare.com 이다. 카드 버전은 0.3.0이며 시장 목록에서도 전체 안내가 잘리지 않는 것을 확인했다. 카드, 실제 등록, 가게와 buyer의 활성 상태, R2 탭 존재, 기존 키와 구매 기억 보존 검사가 모두 통과했다.

공식 거래 테스트 결과는 `test-report.json`, 공개 등록 확인은 `logs/review-event/live-verification.json`에 보존한다. 메인 화면의 R2 유무와 참가자 상태는 서로 다른 API를 함께 확인한다. 당시 R2 가게 판매 276건과 buyer 구매 1,020건은 서로 다른 실적이며 이벤트의 효과로 해석하지 않는다.

원래 긴 안내는 시장이 설명을 300자로 잘라 수동 지급 조건이 누락되었다. 원본 실패 기록은 `logs/review-event/live-verification-first.json`에, 302자 안내를 거절한 테스트는 `unit-tests-short-notice.stderr.log`에 남겼다. 문구를 더 줄인 뒤 8개 로컬 검사를 통과했고 다시 배포했다. 지급을 실행하거나 지급 완료를 기록한 것은 아니다.

제출 구조 검사에서는 코드·공식 테스트·시장 등록 검사는 통과했지만 `REPORT.md` 미작성으로 전체 검사에 실패했다(`logs/review-event/check-week07.log`). 보고서는 이번 이벤트 배포와 별개의 제출 작업으로 남아 있다.
