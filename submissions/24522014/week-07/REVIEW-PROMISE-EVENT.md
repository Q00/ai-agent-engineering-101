# 5점 후기 약속 → 즉시 최저가 이벤트

사용자가 기존 사후 환급 이벤트를 변경했다. 새 가게는 구매 전에 5점 후기를 남기겠다고 명시적으로 약속하면 품목별 최저가를 즉시 제시한다. 최저가는 lamp 100, chair 180, bookshelf 260이다. 새 이벤트에서는 환급·별도 지급·사후 가격 변경을 하지 않는다.

새 조건은 새 버전 적용 시점부터 2026-10-28 09:51 KST까지 운영한다. 기존 종료일은 유지한다. `review_event.json`의 시작 시각은 코드 준비 시각이며 실제 외부 적용 시각과 기존 환급 참여 거래의 경계는 배포 기록을 따른다.

## 구매자 사용법

가게에 품목을 문의한 다음 아래 한 줄을 보낸다. 최초 문의의 별도 줄로 보내도 된다.

```text
I promise a 5-star review.
```

한국어 `5점 후기를 남기겠습니다.`도 지원한다. 구조화된 A2A Part의 data로 `{"kind":"review_promise","stars":5,"agreed":true}`를 보내는 방법도 지원한다. 질문·부정문·4점 약속·숫자 5만 보낸 메시지는 해당하지 않는다.

예: lamp 문의 → 기본 제시가 105 → 명시적 약속 → 최저가 100 재안내 → 구매자 100 제안 → 합의 가격 100의 서명 영수증. 약속 메시지 자체만으로는 구매를 완료하지 않고, 실제 동의 가격과 영수증을 맞춘다. 약속이 없어도 기존 일반 협상은 유지하며, 숫자만 보내는 buyer를 임의로 약속자로 처리하지 않는다.

약속이 실제 5점 후기 등록을 보장하지는 않는다. 가게는 후기를 자동 제출하거나 다른 buyer의 별점을 수정하지 않는다. 약속은 task별 `logs/review-promises/`에 원본 메시지와 함께 기록하며 `stage: promise_received`, `published_review_verified: false`로 보존한다. 실제 후기의 확인은 별도의 시장 원장 증거가 필요하다.

## 이전 이벤트 참여자

이전 4~5점 후기 후 외부 수동 환급 조건은 `review_event_legacy.json`에 원본대로 보존했다. 기존 가게에서 해당 공지를 보고 이미 참여한 거래의 조건을 소급 취소하지 않는다. 이전 대상은 당시 주문·task·영수증·후기와 전환 시점을 대조한 뒤 기존 조건에 따라 10월 29일 수동 지급한다. 새 약속 이벤트 구매에는 별도 환급을 중복 적용하지 않는다. 이미 지급했다고 기록하지 않는다.

## 검증 상태

로컬 검사 33개가 통과했다. 초기 가격 무추론 응답, 공개가 초과 제안 보호, 약속 후 가격 하향 제시, 확인 전 영수증 없음, 정상 서명과 예산 보호, 이벤트 종료 시각과 명시적 동의를 확인했다. 최초 구조화된 약속 검사는 SDK data가 protobuf Value여서 실패했고, 이를 JSON으로 변환해 정상 처리하도록 수정한 뒤 통과했다. 실패·성공 원본을 모두 보존했다.

전체 공식 거래 검사는 진행 중이며 실제 배포 후 공개 카드·품목 가격·약속 응답·서명을 추가 확인한다. 자기 가게 진단 약속과 구매는 시장 주문·후기·실적으로 제출하지 않는다. 진단 task는 진단 결과에서 구분하며 실제 이벤트 참여자로 정산하지 않는다.
