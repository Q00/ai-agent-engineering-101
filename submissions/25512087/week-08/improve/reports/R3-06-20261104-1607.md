## Loop bugs found and fixed this cycle
1. **`tune.py` broke on a "code" record in `changes.jsonl`.** Rollback now only considers knob changes.
2. **Wrong rollback target.**
   - Rollback picked the latest knob cycle (R3-02), even though nothing had changed at the previous cycle.
   - The objective drop came from the outage, so this would have reverted the restock and buyer knobs for no reason.
   - Fixes:
     - Rollback now only blames changes made at the previous cycle.
     - `measure.py` counts network errors (`net_errors`).
     - `tune.py` makes no changes and no rollback when a window has more than 20 network errors.
   - This cycle's metrics file was given its `net_errors` (132) by hand, from the same window of the log. The log itself is untouched.
