# 코드 변경 (11/09, 사용자 승인 "1,2 ㄱㄱ")

## 1. seller_r3.find_unit — 체크아웃 거절 unit 제외 + 요구 남은 시간
- `refused_units()`: 키트 로그 끝 3MB에서 `[acp] checkout refused: ... unit u-… is not in stock for this order`를 읽어, 최근 1시간에 2회 이상 거절된 unit을 제시 후보에서 뺀다(30초 캐시). 자정 넘김 처리.
- 키트 코드 확인 결과 이 거절은 (a) 그 unit이 결제 안 된 다른 체크아웃 세션에 잡혀 있거나, (b) buyer 주문의 허용 SKU에 안 맞을 때 난다. R3-24/25의 귤 unit 120건 이상 반복은 (a)로 보이며, 이 변경으로 같은 SKU의 다음 unit을 제시하게 된다.
- `hours_asked()`: 요청에 "N h / hours / 시간"이 있으면 남은 시간이 N 이상인 식품 unit 중 가장 먼저 만료되는 것을, 없으면 가장 오래 남은 것을 고른다.
- **적용하려면 키트 재시작 필요**(seller 코드는 시작할 때 읽음).

## 2. 서명률을 진짜 협상 기준으로 (measure.py, tune.py)
- measure: `real_talks` = 오프닝 − 장난성 저가(최고 제안 < 하한가 10%, 미서명) − 반복 SKU 이탈(창 안에서 같은 SKU 이탈 10회↑). `real_accept_rate` = 서명 / real_talks. NUM_KEYS·merge에 추가.
- tune: ask_of_list 규칙이 real_accept_rate를 쓴다(80%↑이면 +0.02, 40% 미만이면 −0.03). 11/09 이전 측정 파일은 기존 방식으로 대체.
- 현재 로그(11/8 11:42~)로 계산: 오프닝 3,503 → 진짜 협상 1,428(장난성 669, 반복 이탈 1,406), 서명률 26% → 64%. 인하 제안이 더 이상 나오지 않는다.
