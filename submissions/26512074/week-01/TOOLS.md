'write_note'는 에이전트가 'notes.txt'를 읽고 계산한 결과를 새로운 파일에 저장할 수 있도록 추가한 tool입니다. tool 설명을 "Write content to a text file in the working directory."라고 작성한 이유는 모델이 이 tool의 목적과 파일을 저장할 수 있는 위치를 명확하게 이해하고 적절한 상황에서 선택할 수 있도록 하기 위해서입니다. 'path'는 내용을 저장할 파일의 경로를 지정하고, 'content'는 파일에 저장할 내용을 지정합니다. 구현에서는 'w' 모드를 사용하여 기존 파일의 내용을 덮어쓰도록 했으며, read_file과 동일하게 working directory 밖의 경로에는 접근할 수 없도록 제한했습니다.
