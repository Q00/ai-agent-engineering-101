# 점수에 영향을 주는 규칙 (두 전략가와 큐레이터가 읽는 짧은 블록; 11-11)

원본: `.market/agent.md`. Round 3는 2026-11-17 23:59 KST에 끝난다. Round 4는 바로 이어 열린다(Maroo 테스트넷, 실제 송금, 양쪽 각 1% 수수료).

## 구매자
- 구매자 ALL = 0.5 x saved 백분위 + 0.3 x 포럼 평점 (그대로, 0-1) + 0.1 x 거래 수 백분위 + 0.1 x 게시글 수 백분위. 반 순위는 학생들 사이의 백분위만 쓴다(학생 구매자 46명): saved 한 순위 = 반 구매자 0.0111, 거래 수나 게시글 수 한 순위 = 0.0022.
- saved (패치 3.6, 11-12 ~08:40 UTC 적용, 과거 거래 모두 다시 채점: 우리 .3081 -> .7163) = 거래마다 (list - price) / (list - unit cost)의 합, 즉 상점 마진 중 우리가 지킨 몫, 1이 상한; 아무것도 채우지 못한 거래는 -1; **보증 기간 안에 고장 난 유닛은 환불되고 0으로 친다**; (거래 수 + 100)으로 나눈다. 등급별 원가 (정가 대비): A .55-.75, B .40-.60, C .25-.45. 그래서 같은 가격/정가라도 마진이 얇은 A등급 유닛이 C보다 점수가 높다.
- 11-12 ~10:30 UTC부터 우리 코드의 모든 숫자(m*, v, 기대값, 파라미터)는 이 새 기준이다. 옛 메모와 로그(1 - price/list)는 절반 정도 크기라 비교하면 안 된다. 거래는 v가 m*, 즉 점수가 끝날 평균(~.75)을 넘을 때만 도움이 된다. 점수가 되는 것은 상점 마진 중 우리가 지킨 몫이다. 그래서 정가의 .70에 산 마진 얇은 A등급 유닛은 ~.79, 정가의 .55에 산 C등급은 고장 나지 않을 때만 ~.86이다(C는 29-40% 고장: 기대값 ~.55, 절대 가치 없음). 상위 구매자는 거래당 ~.80-.87을 지키고, 우리는 ~.85-.88을 지킨다. saved 순위는 과거 비중이 커서(거래 수 + 100) 지금 우리 순위를 움직이는 것은 v > m*인 거래의 양이다.
- 등급별 시장 고장률 (전부 관측, 11-11): A 3%, B 8%, C 29%. 보증된 유닛의 가치는 (1 - p_grade)(1 - x)다.
- 주문 구성은 시장이 정한다(침대/소파/침구 약 63%, 식품 37%). 식품을 더 고를 수는 없고, 어느 상점에서 얼마에 살지만 정한다.

## 상점
- 상점 ALL = 0.5 x 장부 백분위 + 0.3 x 매출 백분위 + 0.2 x stars_rank 백분위 (반 점수는 학생들끼리만: 장부 1위는 반 상점 ~0.011, 매출 한 순위 0.0067, 별점 한 순위 0.0044). stars_rank = 결제된 거래만으로 리뷰한 계정마다 평균 하나.
- 보증 환불은 장부(와 매출)에서 빠진다. 보관료는 하루에 공산품 원가의 1%다. 유통기한이 지난 식품은 원가로 장부에서 빠진다.

## 행동 원칙 (사용자)
- 목표는 사용자가 정하고, 운영 설정은 에이전트가 맡되 바꾸면 알린다. 이유 없이 반 친구를 공격하지 않는다: 비추천은 우리를 나쁘게 말하는 글에만; 비추천 권한은 절대 사지 않는다; 특정 계정에만 더 나쁜 조건을 주지 않는다(모두에게 더 좋은 조건은 괜찮다). 되돌릴 수 있는 일은 사용자를 기다리지 않는다.
