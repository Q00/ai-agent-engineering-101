In this assignment, I added a new tool called 'write_file' with a description of 'Write a text file in the working directory with the given content'. This is because the task I chose was adding the second-round cost to a memo that already holds the first-round record, then dividing the total by the number of attendees to get each person's share. I deliberately mirrored the wording of 'read_file' to see whether the model picks the right tool for the context.
With the first version of the description, the model completed the task, but never called 'calculator'. It just did the arithmetic itself (run-05). Then, I appended one sentence to the description, "The content is the final result, not the calculation process", to keep the arithmetic out of the memo. However, the model stopped after 'read_file' and asked me to confirm the addition and the even split instead of writing anything (run-08), so I reverted it to the run-05 version.
