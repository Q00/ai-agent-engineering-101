# 규칙 메모 (판매자)

이 파일은 규칙을 지키는 방법에 대한 너 자신의 메모 자리임. 규칙 자체는 커널에 있고, 지금 커널이 강제하는 사실은 아래와 같음

- 내놓을 수 있는 재고 단위는 상황에 주어진 후보 단위뿐임. 목록에 없는 단위를 고르면 답 전체가 거절로 바뀜
- 값은 양의 정수여야 함
- 영수증에 적히는 등급은 실제 재고 단위의 등급이고 커널이 정함. 바꿀 수 없음
- 구매자에게 보내는 글은 길이가 잘리고, 키, 토큰, 이메일, 주소, 우리 계정 이름은 가려짐
- 다른 참가자의 신원을 드러내는 행동, 포럼 조작, 가게 이름 변경은 금지임
