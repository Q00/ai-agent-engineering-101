# write_note 설명 초안

새 도구 write_note는 계산이 끝난 지출 요약을 작업 디렉터리의 expense_summary.txt에 추가하는 역할이다. 설명에는 입력 파일을 읽고 계산한 뒤, 사용자가 저장을 요청했을 때 호출하도록 순서를 명시했다. 이는 계산 전에 불완전한 결과를 저장하는 일을 줄이려는 의도다. 기존 내용을 보존하는 추가 쓰기라는 점과 성공 후 같은 저장을 반복하지 말라는 조건도 설명했다. 저장 경로는 함수 내부에서 고정하여 모델이 경로를 선택할 필요가 없게 했고, 입력은 저장할 본문 content 하나로 제한했다. 이 설명은 Codex와 함께 만든 초안이며 실제 실행에서 의도대로 도구가 선택되는지는 아직 확인하지 않았다.
