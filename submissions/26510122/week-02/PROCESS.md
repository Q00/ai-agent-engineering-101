# 실험 과정

- Codex와 함께 시작 코드를 읽고 실험을 준비했다. TASK.md와 원본 app.log는 실험 전 커밋 9e00637에 고정했다.
- 두 하네스와 공통 도구는 시작 코드 그대로 비교한다. API 제공자만 OpenRouter로 설정하며 모델은 nvidia/nemotron-3.5-lightning:free로 동일하게 고정한다.
- ReAct는 전체 대화 기록으로 다음 행동을 결정한다. Plan-then-Execute는 별도 계획 대화와 실행 대화를 사용하며 재계획은 최대 1번이다.
- 공통 도구는 읽기 전용이라 두 방식 모두 사람 개입은 0으로 예상된다.
- 저장소 루트 .env를 값 출력 없이 읽는 실행 파일을 추가했다. 두 하네스의 코드, 입력, 성공 판정은 수정하지 않았다.
