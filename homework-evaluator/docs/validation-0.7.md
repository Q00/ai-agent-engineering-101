## 해결한 처리 문제와 남은 한계

- 파일 전체는 그대로 제공하고 최대 40줄마다 근거 ID를 붙였습니다. 모델의 임의 줄 번호나 인용문 복사 오류를 보정해 통과시키지 않습니다. ID가 가리키는 구간이 주장을 뒷받침하는지는 의미 검토가 필요합니다.
- 모델의 읽은 파일 자기신고는 실제 읽기를 증명하지 못해 제거했습니다. 제공 파일·원문·해시·선택 규칙은 도구 기록에 남고 의무별 관측은 고정 키로 받아 중복·누락을 막습니다.
- 종합 단계가 새 요건·새 감점을 만들지 않으며, 기존 항목 검토로 감사 상태를 조립합니다. reviewed는 정답·직접 실행 보증이 아닙니다.
- 가산 후보를 먼저 고정한 뒤 후보별 관련 파일·의존 파일·요청 로그를 온전히 평가합니다. 긴 로그는 파일 단위 묶음으로 나누고 보수적으로 합칩니다. 크기 상한을 넘으면 근거를 자르지 않고 처리 미완료로 남깁니다.
- 인식 가능한 실제 호출/결과 표지만 코드로 집계해 과거 상태와 구분합니다. 지원하지 않는 로그는 unknown이며, 명시 오류 표지의 부재는 실제 거부 0을 보증하지 않습니다.
- 표현이 다른 질문은 교수자가 연결할 수 있고, 한 번의 답변을 여러 지정 패킷에 전파하면서 관련 작업만 새로 판단합니다. 기존 원문·판정은 보존합니다.
- 신규 호출과 입력 변형의 의미 판단 및 자유 가산은 여전히 달라질 수 있습니다. 위 수치가 완전한 자동 채점의 수용 기준을 모두 충족했다고 주장하지 않습니다.
- 교수자의 항목별 참조 정답이 없어 채점 정확도는 측정하지 않았습니다. 공식 배점 그룹·비중은 교수자 확정 사항입니다.
- Opus는 Claude CLI 사용량 한도로 검증하지 못했습니다. Codex 경량 모델 결과를 상위 모델 결과로 일반화하지 않습니다.

탐색 중의 프로토콜 거부·줄 번호/인용 오류·입력 크기 제한·자기신고 중복 실행은 최종 30조건과 분리해 runs/에 보존했습니다. 실패를 학생 감점으로 해석하지 않았습니다.
